\section{Curves}

\begin{definition}[Curve]

A curve \(C\) is a 1-d subset of \(\mathbb{R}^n\), for \(n>1\). It is usually convenient to describe a curve by a parametrisation, \(\boldsymbol{x}(t)\), which maps a real interval \(\left[t_0, t_1\right]\) into \(\mathbb{R}^n\). This is a vector-valued function

\[
\mathbf{x}(t)=x_1(t) \mathbf{e}_2+x_2(t) \mathbf{e}_2+\ldots+x_n(t) \mathbf{e}_n,
\]

where \(\left\{\mathbf{e}_1, \mathbf{e}_2, \ldots, \mathbf{e}_n\right\}\) denote the Cartesian unit vectors

\end{definition}
