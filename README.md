# Durham University Math Notes

A collection of LaTeX notes covering modules covered in Durham from Y2 onwards.

## Overview

This repository serves as a collection of my notes from university following year one. My set up mimics Gilles Castels snippet based LaTeX system and allows me to create these PDF's quickly. 

Within these notes contains formatting for the main environments used in LaTeX which is useful for using these sheets as reference material. Furthermore, a mistakes log categorises common mistakes, tips and method for each chapter as they come out.
